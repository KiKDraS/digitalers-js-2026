Conceptos básicos

¿Qué es la Programación?

La Programación es la habilidad de escribir y organizar instrucciones para obtener un resultado

El proceso de la programación (programar) requiere de los siguientes pasos

  1. Entender el problema que tenemos que resolver
  2. ¿Qué datos necesito?
  3. ¿Cómo puedo utilizar la resolución?
  4. ¿Cuáles son mis limitantes?

¿Qué es un Programa?

Un Programa es un conjunto de instrucciones que se agrupan para lograr un OBJETIVO

¿Qué es un Lenguaje de Programación?

Un Lenguaje de Programación es una HERRAMIENTA que permite la comunicación con el elemento (celular, computadora, microondas, auto, página web, etc) que va a ejecutar el Programa (realizar la serie de pasos que resuelven una tarea)

¿Cómo elijo Lenguaje de Programación?

  • ¿Qué problema tengo que resolver?
  • ¿Quién tiene que resolver el problema?
  • ¿Qué limitantes tiene el Lenguaje?
  • ¿Qué tan cómodo me siento con el Lenguaje?

Tipos de Lenguaje de Programación

  • Forma de tipado - ¿Qué tan estricto es el Lenguaje con el Programador para forzarlo a escribir tipo de dato
    • Fuertemente tipado (muy estricto) - El Programador está obligado a siempre escribir el tipo dato (Java, C++)
    • Debilmente tipado (no exigente) - El Programador NO está obligado a escribir el tipo de dato porque el Lenguaje de Programación puede inferirlo utilizando el valor (JavaScript, Kotlin, PHP)
  • Tipo de tipado - ¿El Lenguaje pde Programación permite modificar el tipo de dato a lo largo de la Ejecución del Programa?
    • Tipado estático (no) - Una vez declarado tipo de dato. No puede cambiar (Java, Kotlin)
    • Tipado dinámico (si) - Una vez declarado tipo de dato, puede cambiar (JavaScript, Python)

Lenguaje JavaScript

Lenguaje pensado para otorgar interactividad a los navegadores web. Por este motivo se lo conoce como "Lenguaje Web"

Evolución del Estándar del Lenguaje

  • 1995 - Brendan Eich - Creación
    1. ECMAScript 1ra Edición - 1997 - Estándar
    2. ECMAScript 2da Edición - 1998 - Revisión
    3. ECMAScript 3da Edición - 1999 - Revisión
    4. ECMAScript 4ta Edición - 2000 (no está disponible - pretendía crear estándar)
    5. ECMAScript 5ta Edición - 2009 - Estándar (Estándar que todo navegador reconoce en su totalidad)
      • var - Única palabra reservada para que el Lenguaje sepa que queremos crear una variable
    6. ECMAScript 6ta Edición - 2015 - Estándar actual (ES6)
      • var - No se recomienda su uso
      • let - Palabra reservada para el que el Lenguaje sepa que queremos crear una variable cuyo valor puede cambiar a lo largo de la Ejecución del Programa
      • const - Palabra reservada para el que el Lenguaje sepa que queremos crear una variable cuyo valor NO puede cambiar a lo largo de la Ejecución del Programa
    7. ECMAScript 7ma Edición - 2016 - Revisión
  • 2009 - Ryan Dhal crea Node.js
    • Node.js es un interprete de JavaScript
    • Entorno de desarrollo de JavaScript
